# Contabilidade parametrizada

MVP simples do sistema contábil parametrizado.

O contrato de implementação desta fase está em [`specs/README_specs_plan.md`](specs/README_specs_plan.md), com escopo inicial limitado às specs 00-02:

- scaffold do projeto;
- convenções canônicas de nomes e tipos;
- plano de contas (`P_t` / `\mathcal P_t`) como `DataFrame` validado;
- template de plano de contas para empresa comercial simples.

Ficam fora desta fase eventos, lançamentos, Diário, Razão, balancete, demonstrações, workbook Excel e qualquer implementação tributária.
